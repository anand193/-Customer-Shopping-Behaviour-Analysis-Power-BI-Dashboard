# 🛍 Customer Shopping Behaviour Analysis – Power BI Dashboard

## 📌 Project Overview
This project analyzes customer shopping behavior to understand purchasing patterns, revenue distribution, demographic trends, and seasonal performance. The interactive Power BI dashboard provides business insights that help improve marketing strategies and customer targeting.

---

## 🎯 Business Objective
The goal of this project is to:
- Analyze overall revenue performance
- Understand customer demographics (age, gender, location)
- Identify high-performing product categories
- Study seasonal sales trends
- Evaluate shipping preferences
- Improve customer segmentation strategies

---

## 📊 Key Performance Indicators (KPIs)
- 💰 Total Revenue: $233K
- 👥 Total Customers: 4K
- ⭐ Average Review Rating: 3.75
- 🛒 Avg Previous Purchases: 25.35
- 🎂 Average Customer Age: 44.07

---

## 🗂 Dataset Features
The dataset includes:
- Customer ID
- Age
- Gender
- Location
- Category
- Season
- Shipping Type
- Review Rating
- Previous Purchases
- Revenue

Data cleaning and transformation were performed using Power Query.

---

## 🛠 Tools & Technologies Used
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling

---

## 📈 Dashboard Features
- Interactive slicers (Category, Season, Gender, Location)
- Revenue breakdown by:
  - Color
  - Gender
  - Location (Map Visualization)
  - Season
  - Category
  - Shipping Type
- KPI cards for quick executive insights
- Trend analysis for seasonal comparison

---

## 🔍 Key Insights
- Clothing category generated the highest revenue (~$104K).
- Male customers contributed higher revenue compared to female customers.
- Fall season recorded the highest sales performance.
- Revenue distribution is geographically spread across U.S. states.
- Free Shipping and Express Shipping are widely preferred options.
